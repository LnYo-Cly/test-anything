## test-anything v0.2.0

## English

`ta` can now test command-line programs, keeps evidence of every failure on disk, and tests itself.

### Features

- `cli.run` step: runs a program without a shell, with `args`, `cwd`, `env`, `stdin` and a timeout. The result has `exit_code`, `stdout`, `stderr`, and `json` when standard output is JSON.
- A program that cannot be started exits 4; a program that exceeds `timeout_ms` is killed and exits 5. A non-zero exit code is a result for assertions, not an error.
- Failure bundles: every case that does not pass gets a directory under `.ta/failures/` with `case.yaml`, `report.json` and `meta.json`. `meta.json` is written last, so a directory without it is incomplete. `--bundle-dir <directory>` moves the bundles and `--no-bundle` turns them off.
- `--output json` and the text output name the bundle of each failed case.
- `ta run --var name=value` sets a variable for every case of the run and overrides `vars:` in the case file. A malformed `--var` exits 2.
- Self-test suite: `tests/self/` uses `ta` to test `ta`, and runs on Linux, macOS and Windows in CI.

### Notes

Failure bundles contain step arguments and results, which may include secrets. Keep `.ta/` out of version control.

### Not yet available

`ta lint`, `ta schema` and filtering by project, suite, layer or tag come in later releases.

### Install

Download the archive for your platform below, extract it, and put `ta` on your `PATH`. Verify the download with `SHA256SUMS`.

| Platform | Archive |
| --- | --- |
| Linux x86_64 | `ta-v0.2.0-x86_64-unknown-linux-musl.tar.gz` |
| Linux arm64 | `ta-v0.2.0-aarch64-unknown-linux-musl.tar.gz` |
| macOS Intel | `ta-v0.2.0-x86_64-apple-darwin.tar.gz` |
| macOS Apple silicon | `ta-v0.2.0-aarch64-apple-darwin.tar.gz` |

The binaries are not code-signed. On macOS, run `xattr -d com.apple.quarantine ta` if the system blocks it.

## 中文

`ta` 现在可以测试命令行程序，把每次失败的证据写到磁盘上，并用自己测试自己。

### 功能

- `cli.run` 步骤：不经 shell 启动程序，支持 `args`、`cwd`、`env`、`stdin` 和超时。结果包含 `exit_code`、`stdout`、`stderr`，标准输出是 JSON 时还有 `json`。
- 程序无法启动时退出 4；超过 `timeout_ms` 的程序会被终止并退出 5。非零退出码是供断言判断的结果，不是错误。
- 失败包：每个未通过的用例在 `.ta/failures/` 下有一个目录，含 `case.yaml`、`report.json` 和 `meta.json`。`meta.json` 最后写入，没有它的目录视为不完整。`--bundle-dir <目录>` 改变位置，`--no-bundle` 关闭失败包。
- `--output json` 和文本输出会给出每个失败用例的失败包路径。
- `ta run --var name=value` 为本次运行的所有用例设置变量，覆盖用例文件中的 `vars:`。`--var` 格式错误时退出 2。
- 自测套件：`tests/self/` 用 `ta` 测试 `ta`，在 CI 的 Linux、macOS、Windows 上运行。

### 注意

失败包包含步骤参数和结果，其中可能有密钥。不要把 `.ta/` 提交到版本库。

### 尚未提供

`ta lint`、`ta schema` 以及按项目、套件、层级、标签筛选将在后续版本提供。

下载对应平台的压缩包，解压后把 `ta` 放到 `PATH` 中。可用 `SHA256SUMS` 校验下载文件。

| Windows x86_64 | `ta-v0.2.0-x86_64-pc-windows-msvc.zip` |

二进制文件没有代码签名。macOS 如果拦截运行，执行 `xattr -d com.apple.quarantine ta`。
