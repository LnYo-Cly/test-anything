## test-anything v0.1.0

The first release of `ta`, a single-binary test runner for coding agents and developers. This release covers HTTP API testing.

`ta` 的第一个发布版本。`ta` 是面向编程 Agent 和开发者的单文件测试工具，本版本支持 HTTP 接口测试。

### Features / 功能

- `ta run <files or directories>` runs YAML test cases in path order. / 按路径顺序运行 YAML 用例文件或目录。
- `http.request` step with method, URL, headers, query, JSON or text body, and a timeout. / `http.request` 步骤，支持方法、URL、请求头、查询参数、JSON 或文本请求体以及超时。
- Assertions on any step result with JSONPath: `equals`, `not_equals`, `contains`, `exists`. / 用 JSONPath 对步骤结果断言：`equals`、`not_equals`、`contains`、`exists`。
- Variables: `vars`, `save` and `${name}` references between steps. / 变量：`vars`、`save`，以及步骤间的 `${name}` 引用。
- `--output json` writes one JSON object with per-step results and assertion details. / `--output json` 输出单个 JSON 对象，包含每一步的结果和断言细节。
- Exit codes: 0 passed, 1 assertion failed, 3 invalid case, 4 environment error, 5 timeout. / 退出码：0 通过、1 断言失败、3 用例无效、4 环境错误、5 超时。
- Invalid case files are rejected before anything runs, with line and column numbers. / 用例无效时不执行任何用例，报错带行列号。
- `ta` no longer crashes when the program reading its output exits early. / 读取输出的程序提前退出时，`ta` 不再崩溃。

### Not yet available / 尚未提供

`ta lint`, `ta schema`, the command-line driver and failure bundles come in later releases.

`ta lint`、`ta schema`、命令行驱动和失败包将在后续版本提供。

### Install / 安装

Download the archive for your platform below, extract it, and put `ta` on your `PATH`. Verify the download with `SHA256SUMS`.

下载对应平台的压缩包，解压后把 `ta` 放到 `PATH` 中。可用 `SHA256SUMS` 校验下载文件。

| Platform / 平台 | Archive / 压缩包 |
| --- | --- |
| Linux x86_64 | `ta-v0.1.0-x86_64-unknown-linux-musl.tar.gz` |
| Linux arm64 | `ta-v0.1.0-aarch64-unknown-linux-musl.tar.gz` |
| macOS Intel | `ta-v0.1.0-x86_64-apple-darwin.tar.gz` |
| macOS Apple silicon | `ta-v0.1.0-aarch64-apple-darwin.tar.gz` |
| Windows x86_64 | `ta-v0.1.0-x86_64-pc-windows-msvc.zip` |

The binaries are not code-signed. On macOS, run `xattr -d com.apple.quarantine ta` if the system blocks it.

二进制文件没有代码签名。macOS 如果拦截运行，执行 `xattr -d com.apple.quarantine ta`。
