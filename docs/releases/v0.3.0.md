## test-anything v0.3.0

## English

Check cases without running them, get a machine-readable description of the case format, and install `ta` with one command.

### Features

- `ta lint <files or directories>` validates cases with exactly the checks `ta run` applies before it starts, reports every problem in every file at once, and runs no step. It accepts `--var` like `ta run`. Exit 0 when valid, 3 otherwise; `--output json` gives `ok`, `files` and `errors`.
- `ta schema` prints a JSON Schema (draft 2020-12) of a case file with every registered step's arguments and description. Editors such as yaml-language-server can use it for completion and validation.
- One-line install on Linux and macOS: `curl -fsSL https://raw.githubusercontent.com/LnYo-Cly/test-anything/main/install.sh | sh`.
- One-line install on Windows: `irm https://raw.githubusercontent.com/LnYo-Cly/test-anything/main/install.ps1 | iex`.
- The installers pick the build for the system and CPU, verify SHA-256, need no administrator rights, and are mirrored on jsDelivr. `TA_VERSION`, `TA_INSTALL_DIR` and `TA_DOWNLOAD_URL` adjust them.
- New native build for Windows on Arm64 (`aarch64-pc-windows-msvc`).
- The README is now a short front page in English and Chinese; the full reference is in `docs/guide.md`.

### Changes

- Exit code 9 is no longer returned by any command; it stays reserved.

### Not yet available

Filtering cases by project, suite, layer or tag comes in a later release.

### Install

Use the one-line installers above, or download the archive for your platform below, extract it, and put `ta` on your `PATH`. Verify the download with `SHA256SUMS`.

| Platform | Archive |
| --- | --- |
| Linux x86_64 | `ta-v0.3.0-x86_64-unknown-linux-musl.tar.gz` |
| Linux arm64 | `ta-v0.3.0-aarch64-unknown-linux-musl.tar.gz` |
| macOS Intel | `ta-v0.3.0-x86_64-apple-darwin.tar.gz` |
| macOS Apple silicon | `ta-v0.3.0-aarch64-apple-darwin.tar.gz` |
| Windows x86_64 | `ta-v0.3.0-x86_64-pc-windows-msvc.zip` |
| Windows arm64 | `ta-v0.3.0-aarch64-pc-windows-msvc.zip` |

The binaries are not code-signed. On macOS, run `xattr -d com.apple.quarantine ta` if the system blocks a manually downloaded binary.

## 中文

不执行就能检查用例，获得机器可读的用例格式说明，并且一行命令即可安装 `ta`。

### 功能

- `ta lint <文件或目录>` 用与 `ta run` 开始前完全相同的检查校验用例，一次报出所有文件的所有问题，不执行任何步骤。与 `ta run` 一样接受 `--var`。有效退出 0，否则退出 3；`--output json` 给出 `ok`、`files`、`errors`。
- `ta schema` 输出用例文件的 JSON Schema（draft 2020-12），包含每个已注册步骤的参数与描述。yaml-language-server 等编辑器可以用它补全和校验。
- Linux 与 macOS 一行安装：`curl -fsSL https://raw.githubusercontent.com/LnYo-Cly/test-anything/main/install.sh | sh`。
- Windows 一行安装：`irm https://raw.githubusercontent.com/LnYo-Cly/test-anything/main/install.ps1 | iex`。
- 安装脚本按系统与 CPU 选择构建，校验 SHA-256，不需要管理员权限，并在 jsDelivr 有镜像。可用 `TA_VERSION`、`TA_INSTALL_DIR`、`TA_DOWNLOAD_URL` 调整。
- 新增 Windows Arm64 原生构建（`aarch64-pc-windows-msvc`）。
- README 改为简洁的中英文首页，完整参考移到 `docs/guide.md`。

### 变更

- 不再有命令返回退出码 9，该码保留。

### 尚未提供

按项目、套件、层级、标签筛选用例将在后续版本提供。
